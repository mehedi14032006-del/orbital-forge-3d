# ORBITAL FORGE 3D
.github/workflows/build-apk.yml

A 3D Planetary Automation & Orbital Defense Simulator built with **Three.js r187**, custom **GLSL Shaders**, **Unreal-style Bloom**, a procedural **Web Audio API Synthesizer**, and **Capacitor 8** for native Android (API 36) packaging.

## How to Download the Android `.apk`
1. Open the **Actions** tab of this GitHub repository.
2. Tap the latest **Build Android APK** workflow run (wait ~2–3 minutes for the green checkmark).
3. Scroll down to **Artifacts** and download **`orbital-forge-3d-apk`**.
4. Unzip and install `app-debug.apk` on your Android phone.

## Core Features
- **3D PBR Graphics & Shaders:** Procedural cratered basalt terrain with bump mapping, Fresnel planetary atmosphere shader, reactive energy shield dome, and volumetric rocket thruster exhaust.
- **Automation & Defense Loop:** Place Mining Drills on Titanium & Plasma veins, expand your power grid with Fusion Relays, defend against escalating Meteor & Rogue Drone waves with Laser Turrets and Plasma Mortars, and launch Orbital Supply Rockets to advance Tiers.
- **Mobile-First Controls:** Smooth touch orbit & pinch-to-zoom camera, floating telemetry HUD, auto-save (`localStorage`), and 1x/2x speed toggle.
